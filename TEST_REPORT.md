# Отчёт о тестировании LibraryApp

## Дефекты, выявленные при отладке

| ID | Описание | Фактический результат | Статус |
|---|---|---|---|
| 1 | Выдача несуществующей книги вызывает необработанное исключение | NullReferenceException, аварийное завершение | Исправлен |
| 2 | Повторная выдача уже выданной книги разрешается | Сообщение о выдаче, искажение состояния | Исправлен |
| 3 | Возврат невыданной книги некорректно меняет состояние | Сообщение о возврате без проверки | Исправлен |
| 4 | Дубликат книги добавляется без ошибки (инспекция) | Дубликат сохранялся в списке | Исправлен |

## Методика

- Ручное функциональное тестирование — прогон демонстрационного сценария.
- Отладка — точки останова в BorrowBook, ReturnBook, FindBook; окна Locals и Watch.
- Статический анализ — анализаторы Roslyn, AnalysisLevel = latest-recommended.

## Итоги

Все сценарии после исправлений обрабатываются корректно, сборка без предупреждений критического уровня.

## Рекомендации

- Покрыть BorrowBook и ReturnBook модульными тестами xUnit.
- Заменить вывод в консоль логированием.
- Выделить интерфейс ILibrary для тестируемости.
